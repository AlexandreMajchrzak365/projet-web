# Maquette

Déposez ici les photos de votre maquette papier : une photo par feuille, plus le plan de navigation.

Donnez à chaque photo le nom de la page qu'elle montre, pour qu'on sache ce qu'il y a dedans sans l'ouvrir. Par exemple :

- `plan.jpg` : le plan de navigation
- `accueil.jpg` : la page d'accueil
- `galerie.jpg`, `regles.jpg`… : les autres pages, avec le même nom que leur futur fichier HTML
